# 013 · 백테스트의 방어가 실계좌까지 오는가

**상태: 대기 — 11/25 뒤** · 2026-10-01 외부 검토(Codex)에서 나옴

## 무엇

노출 보정 낙폭 우위 10~16%p는 **백테스터가 잰 값**이다. 배포된 시스템은
다르게 돈다.

| | 백테스트 | 실계좌 |
|---|---|---|
| 1회 / 일일 한도 | $5 / $10 (`backtest-cli.js` `BASE_ENV`) | $6.7 / $13.4 |
| 주문 | 종가 기준 | 금액 시장가, 15분 주기, 개장~종료 1시간 전 |
| 추종 | 장부 = 보유 | 실계좌가 장부를 **한도 안에서** 따라감(㉘) |

> **⚠️ 10/1 정정 — 매도에는 1회 한도가 없다.** `ledger-sync.js`는 매도를 보유의 98%까지
> 한 번에 계획하고, 매도 체결액만큼 그날 매수 여력을 돌려준다. **$6.7·$13.4는 매수 쪽
> 한도다.** 그러니 아래 「며칠 늦게 따라간다」는 **위험을 줄이는 매도가 아니라 다시
> 사는 재진입 쪽**에서 주로 생긴다. 둘을 갈라서 잰다.

밴드·최소주문은 백테스트에도 있다. 없는 것은 **실제 한도·시장가 체결·시차**다.
급락 때 목표가 크게 움직이면 일일 매수·1회 한도 때문에 **실계좌가 며칠 늦게
따라갈 수 있다** — 방어가 필요한 순간에 가장 느리다.

9월은 이것을 재지 못했다 — 추세가 목표를 $2.06 움직였고 밴드 안이라 보유는
안 움직였다(10/1 정정).

## 할 것

1. 백테스트를 **운영 한도($6.7 / $13.4)**로 한 번 다시 잰다. ⑱에 「재기 전에
   판정 기준을 먼저 적는다」고 해 뒀으므로 기준부터 적는다
2. 같은 입력으로 **목표 비중 → 밴드 → 주문 → 보유량**을 끝까지 따라가, 위기
   구간에서 목표와 보유의 차이가 며칠 만에 닫히는지 센다 (007과 함께)
