## 부호는 음수인데 왜 결함이 아닌가

**9/9의 비중 갭(실제 주식비중 − 목표)이 26/26 전부 양수다.**

```
스텝 26 | 최소 0.0157 · 최대 0.0167
목표보다 0.1%p 이상 미달인 사이클: 0 / 26
```

**하루 내내 목표보다 +1.6%p 더 들고 있었다.** 못 채운 구간이 한 번도 없다.
체결 경로 결함은 정의상 **실제 < 목표**로 나타나는데 부호가 반대다.

**그러면 목표미달 항목은 왜 음수인가.** 이 항목은 `(실제−목표) × 벤치수익률`
이고, 9/9는 벤치마크가 **내린** 날이다(구조적 +0.0121이 그것을 말한다 —
`(목표−1)`이 음수인데 곱이 양수다). 목표보다 더 들고 있는데 시장이 내렸으니
곱이 음수다. **덜 사서 뒤처진 것이 아니라 더 들고 있어서 더 내린 것이다.**

**+1.6%p는 밴드(5%) 안이라 주문이 안 나간다.** 9/4에 적은 상태 그대로다 —
가장 가까운 SCHD가 밴드까지 $0.77 남아 있었다. **조용한 것은 고장이 아니다.**

## 곁에 둘 사실 — 출력이 셸에 먹혔다

터미널 출력을 복사해 옮기는 사이에 `$`+숫자가 위치 파라미터로 전개됐다.
zsh에서 `$0`은 셸 이름, `$1`~`$9`는 빈 문자열이다.

```
-$1.46  →  -.46      (Ⓐ $1이 사라짐)
+$0.04  →  +-zsh.04  (Ⓑ $0이 셸 이름으로)
```

**숫자가 조용히 바뀐다.** `-.46`은 깨진 것처럼 안 보이고 −$0.46으로 읽힌다.
복원은 항목 합으로 검산했다(0.04 − 1.46 + 0.49 − 0.20 = −1.13 = alpha).

**옮길 때는 파일을 거친다** — `npm run paper:alpha > /tmp/a.txt`.
`usd()`가 `$`를 안 쓰게 고치는 것은 출력 형식 변경이라 9월엔 안 한다.
