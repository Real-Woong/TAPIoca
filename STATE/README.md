# STATE — 그날 무엇을 봤는가

매일 아침 텔레그램 보고서를 읽고 확인한 것을 하루 한 장으로 남긴다.
**보고서 자체를 옮겨 적는 곳이 아니다** — 보고서는 텔레그램에 있다.
여기 남기는 것은 **그것을 읽고 무엇을 확인했고 무엇이 걸렸는가**다.

## 세 폴더의 분업

| | 무엇을 담는가 | 고치는가 |
|---|---|---|
| `STATE/` | 그날 본 것 · 확인한 것 · 걸린 것 | 그날 안에서만 |
| `DEVELOPE_IDEA/` | 아직 안 한 것. 후보와 기각 사유 | 상태가 바뀌면 고친다 |
| `develope-log/` | 실제로 한 것 | **고치지 않는다** |

`STRATEGY.md`는 여전히 **지금 무엇이 참인가**만 적는다. 여기서 확인된 사실이
전략을 바꾸면 그때 `STRATEGY.md`를 고치고, 무슨 일이 있었는지는
`develope-log/`에 남긴다. 이 폴더는 그 사이의 관찰 기록이다.

## 한 장의 뼈대

```
# 2026-MM-DD (거래일 뉴욕 YYYY-MM-DD)

## 맞는 것        숫자가 서로 맞는가. 확인한 항목을 적는다
## 걸린 것        모순·이상. 없으면 "없다"고 적는다
## 안 한 것       봤지만 손대지 않기로 한 것과 그 이유
```

**"이상 없음"을 빈칸으로 두지 않는다.** 무엇을 봤는지 안 적으면 안 본 것과
구분되지 않는다 — ⑬이 사흘간 안 걸린 이유가 그것이다.

**손익 해석은 적지 않는다.** "오늘 왜 올랐나"는 여기서 답하지 않는다.
판정은 `STRATEGY.md` §3에 미리 적힌 기준과 날짜로만 한다.
